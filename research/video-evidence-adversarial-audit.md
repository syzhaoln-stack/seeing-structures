# 视频证据卡对抗性审查

审查日期：2026-08-24

审查对象：17 个核心主题中的 51 张视频证据卡。

## 审查标准

不以“视频多”为完成标志，而是以学生能否在不打开完整视频时回答以下问题为标准：

1. 这一卡要我看什么？
2. 一张图是否已经足够？如果不足，必须看哪几十秒？
3. 画面、中文解释、时码和学习任务是否说的是同一件事？
4. 网络较慢、禁用 JavaScript、只用键盘或窄屏时，证据链是否仍成立？
5. 本地关键帧、原平台播放器、中文导看和第三方版权是否有清楚边界？

## 找到并修复的问题

| 严重度 | 攻击方式 | 原问题 | 修复与回归检查 |
|---|---|---|---|
| P0 | 冷启动网络监听 | JavaScript 改写前，原 `iframe src` 可能已请求外站播放器 | 源文档只保留惰性 `data-src`，并用 `noscript` 提供精确时码链接；17 页首屏零外站媒体请求、零运行时视频 iframe。 |
| P1 | 对照源码、审看记录与 manifest | 51 条视频存在手写时码与最终核心时码冲突的风险 | 审看 JSON 成为唯一时间源；生成 manifest，并用 `sync_video_times.py` 同步源页与降级链接。 |
| P1 | 检查“截图是否真在片段内” | 3 个 motion 条目的旧关键帧或观看任务不在短片段中 | 重新选择片段/关键帧，并在生成器与验证器中强制 `clipStart ≤ frameTime < clipEnd`。 |
| P1 | 把中文标注与图像逐张反向核对 | 部分旧导看在讲“黏结长度/破坏面”，画面实际显示“浇筑位置/试验机” | 修正 UcPm61zRATk、cZINeaDjisY、FpO2KImasNo 等关键帧与中文观察任务，使图、标、任务一致。 |
| P1 | 模拟 390px 手机阅读 | 标题和观察任务可能排在卡片之后；截图被裁切，画面上的文字被操作层遮住 | 统一为“标题—导看—图—标识—单一任务—分步解释—来源”；图像使用 `object-fit: contain`，操作条与画面分层。 |
| P1 | 伪装成已授权用户 | 明确禁止画面复用的 YouTube 条目仍可回退到外链缩略图 | `rightsNote` 条目禁止任何 poster 回退；3 张限制卡均为文字占位、无本地帧、无外链缩略图。 |
| P1 | 在干净克隆中重建 | 收集器只识别活动 `src`，惰性化后会得到 0 条；manifest 与截帧脚本又强依赖未入库缓存 | 收集器同时识别 `data-src/src`；生成和截帧改以已审定 JSON 为唯一必需输入，本地元数据只作可选审看缓存。 |
| P2 | 键盘操作 | 键盘载入 motion 后焦点短暂落到 `body` | 挂载后立即把焦点送到“收起视频”；收起后回到原载入按钮。 |
| P2 | WCAG 对比度检查 | motion 状态的白字 / `#b86f00` 约为 3.95:1 | 状态色改为 `#945800`，白字对比度约 5.75:1。 |
| P2 | 桌面窄正文测试 | 1100px 窗口在 Quarto 双侧栏下只余约 566px 正文，三卡仍并排 | 使用容器查询：视频组自身低于 42rem 时改为两列，低于 32rem 时改为单列，不再依赖设备宽度猜测可用正文宽度。 |

## 最终回归范围

- 数据：17 页、51 条唯一来源、48 张可复用低分辨率关键帧、3 条明确权利限制占位。
- 模态：22 条需要运动，最长 90 秒；25 条分步图解；4 条单帧足够。
- 冷启动：桌面与 390px 手机的 17 页均为 3 张预览卡、0 个运行时视频 iframe、0 个外站媒体请求。
- 动作：22 个 motion 均可按精确起止时码载入，`autoplay=0`，关闭后卸载播放器。
- 布局：390px 下展开视频组、中文讲解和分步解释后，无水平溢出、遮挡或卡片重叠；主要操作目标不低于 44px。
- 内容：可靠度页只在明确条件下使用二维联合正态，以 `R=S` 为边界、`R≤S` 为失效域，没有把边缘正态误写成必然联合正态。

## 仍需长期维护的边界

- 外部平台可能下架视频或改变播放参数；审看记录、来源 ID、原作者和时码因此必须保留在仓库中。
- 关键帧只用于针对具体教学主张的低分辨率评论性引用；第三方画面仍归权利人。收到权利人异议时，应改为无画面占位或原创示意图。
- 中文文字是围绕观察任务重写的导看与概括，不是未经授权的逐字字幕复制。
